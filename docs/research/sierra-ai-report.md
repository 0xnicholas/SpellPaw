## 3. 核心产品矩阵

### 3.1 Agent Studio
- 可视化 agent 控制面板，用于构建和管理 AI agent
- 提供 agent 行为追踪、决策可视化

### 3.2 Ghostwriter（明星产品 — "the agent-building agent"）
- 非技术人员可构建生产级 agent
- 输入方式：上传 SOP 文档、对话记录、白板照片、音频录音——或用自然语言描述目标
- 自动生成生产就绪、多语言、多渠道的 AI agent
- 内建 guardrails（护栏/安全边界）
- 自动根据问题标记和主动洞察更新 agent
- 变更完全透明——可审查、验证、发布

### 3.3 Horizon（新发布）
- **长跨度 AI agent**：跨数天数月规划和执行复杂任务
- 核心能力：
  - **长跨度规划**（Long-horizon planning）：将复杂目标拆解为可逐步改进的子步骤
  - **客户上下文**（Customer context）：连接跨对话、系统和触点的客户记忆
  - **结果优化**（Outcome optimization）：个性化决策以最大化满意度和收入
  - **主动触达**（Proactive engagement）：响应现实世界信号，触发最佳行动工作流
- 集成数据源：Google Cloud, Databricks, Snowflake, Redis, AWS

### 3.4 Insights / Explorer
- 用自然语言提问，以 ChatGPT-style 深度研究方式分析 agent 性能
- **Explorer**: 分析 agent 表现，类似 Deep Research for conversations
- **Monitors**: 主动识别需要额外关注的对话
- **Experiments**: 多变量测试，优化对话设计和 agent 性能
- **Observability**: 可视化 agent 的每一步操作——工具调用、知识检索、延迟等

### 3.5 Channels（渠道）
- 一次构建，多处部署
- 支持：语音、在线聊天、SMS、WhatsApp、Email、ChatGPT
- 59 种语言，7×24 可用

## 6. 定价模式

Sierra 开创了一种全新的定价模型——**成果导向定价**（Outcome-based pricing）：

- 仅在 AI agent 达成**特定的、有价值的业务成果**时才收费
- 不再按席位（per-seat）或按对话量（per-conversation）的传统 SaaS 计费
- 配套提供专家 agent 开发团队支持——直接参与部署全流程

## 9. 市场定位分析

### 差异化特点
1. **企业级深度 vs. 浅层聊天机器人** — 不是 FAQ 机器人，而是可执行完整业务流程的自主 agent
2. **Ghostwriter 降低门槛** — 非工程人员可从 SOP/录音构建 agent
3. **成果导向定价** — 与客户业务价值对齐，降低采用风险
4. **Horizon 长跨度能力** — 跨时间维度的 agent 记忆与规划，超越单轮对话
5. **创始人背景** — Bret Taylor 个人影响力带来极大的行业信任和资源
6. **顶级合规矩阵** — 9 项认证涵盖安全、隐私、AI 治理，是进入金融/医疗行业的关键壁垒

### 与同类产品对比
| 维度 | Sierra | Zendesk AI | Intercom Fin | Salesforce Einstein |
|------|--------|------------|-------------|---------------------|
| 定位 | 企业对话 AI 平台 | 客服工单 AI 增强 | 客服对话 AI | CRM 内嵌 AI |
| 定价 | 成果导向 | 传统 SaaS | 按解决量 | 按席位 |
| 构建门槛 | Ghostwriter（非技术可用） | 需配置 | 需配置 | 低代码 |
| 长跨度 agent | ✓ (Horizon) | ✗ | ✗ | 有限 |
| 合规矩阵 | 9 项认证 | SOC2/GDPR | SOC2/GDPR | 企业级 |

## 10. 定位总结

Sierra 的本质是一个**客户生命周期 AI 平台**，覆盖三大价值维度：

| 维度 | 能力 | 说明 |
|------|------|------|
| **服务** (Service) | 智能客服、理赔、退货、抵押贷款 | 处理客户进线，降低支持成本 |
| **增长** (Growth) | 结果优化、upsell、主动推荐 | 在对话中识别机会并驱动收入 |
| **留存** (Retention) | 流失预防、主动触达、客户上下文 | 基于信号的预判性工作流，提升 LTV |

它不是"客服 AI"，而是以对话为载体，贯穿客户全生命周期的 AI 运营平台。
